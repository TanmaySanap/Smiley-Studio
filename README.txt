Smiley Studio Website

How to use:
1. Open index.html in your browser.
2. Edit text, prices, email, phone, and project details inside the HTML files.
3. Edit colors and layout in assets/css/style.css.
4. Edit quotes and interactive behavior in assets/js/main.js.
5. Upload the full folder to Netlify, Vercel, GitHub Pages, cPanel, or any static hosting.

Folder structure:
- index.html: Main landing page
- pricing.html: Pricing page
- projects.html: Project listing page
- contact.html: Contact page
- projects/titan-gym/index.html: Titan Gym demo page
- projects/nova-cafe/index.html: Nova Cafe demo page
- projects/visionx-studio/index.html: VisionX Studio demo page
- projects/eclipse-wear/index.html: Eclipse Wear demo page
- assets/css/style.css: Full responsive styling
- assets/js/main.js: Dark/light mode, quotes, counters, contact form demo, BMI calculator

Note:
The contact forms are frontend demo forms. To receive real messages, connect the form to Formspree, EmailJS, Google Sheets, PHP mail, or a Node.js backend.
